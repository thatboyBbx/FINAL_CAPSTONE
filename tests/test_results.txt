ROOT CAUSE FIXES APPLIED
-------------------------
1. conftest.py — Used SQLAlchemy StaticPool to ensure all SQLite connections
   share a single in-memory database. Without this, each new connection created
   a fresh empty database, causing "no such table" errors during INSERT.

2. conftest.py — Import app.main BEFORE Base.metadata.create_all() to ensure
   all model imports (triggered in main.py) register their tables with
   Base.metadata before table creation.

3. app/services/csp_service.py — _fuzzy_match() changed from token_sort_ratio
   to partial_ratio (rapidfuzz). token_sort_ratio scored "Old Mutual" vs
   "Old Mutual Zimbabwe Limited" at 54 (below threshold=75). partial_ratio
   correctly scores substring containment at 100.
