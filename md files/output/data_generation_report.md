### Column Distributions

| Column | Type | Distribution | Parameters |
|--------|------|-------------|-----------|
| insurer_name | str | Uniform sample | 25 Zimbabwean insurer names |

| solvency_ratio | float | Normal | mean=1.45, std=0.35, clip [0.5, 3.0] |

| year | int | Uniform | range 2018–2024 |

| risk_label | str | Derived from WCS | strong/adequate/watch/distressed |
| anomaly_flag | int | Derived + injected | 0 or 1 |

### WCS Derivation Rule
```
wcs_score = (
    0.35 * min(solvency_ratio / 1.5, 1.0)
    + 0.30 * max(1.0 - claims_ratio, 0.0)
    + 0.20 * min(reserve_adequacy / 1.0, 1.0)
    + 0.15 * min(liquidity_ratio / 1.5, 1.0)
)

if wcs_score >= 0.75:   risk_label = "strong"
elif wcs_score >= 0.55: risk_label = "adequate"
elif wcs_score >= 0.35: risk_label = "watch"
else:                   risk_label = "distressed"
```

### Anomaly Flag Derivation
```
anomaly_flag = 1 if any:
  - claims_ratio > 0.95 AND solvency_ratio < 0.90
  - premium_growth < -0.25 AND reserve_adequacy < 0.60
  - compliance_score < 0.60 AND solvency_ratio < 1.0
  - solvency_ratio < 0.70
else 0
```

### Stress Scenarios (Anomaly Injection)
Exactly 120 rows were generated by applying one of four stress scenarios:
1. **high_claims_low_solvency**: claims_ratio ∈ [0.96, 1.20], solvency_ratio ∈ [0.50, 0.89]
2. **declining_premium_low_reserves**: premium_growth ∈ [-0.40, -0.26], reserve_adequacy ∈ [0.30, 0.59]
3. **low_compliance_low_solvency**: compliance_score ∈ [0.50, 0.59], solvency_ratio ∈ [0.70, 0.99]
4. **regulatory_breach**: solvency_ratio ∈ [0.50, 0.69] (below IPEC 70% hard floor)

**Note on distressed=0**: The WCS weight configuration (0.35 solvency + 0.30 claims + 0.20
reserve + 0.15 liquidity) produces scores above the 0.35 threshold even for most anomaly rows,
because anomaly scenarios target individual metrics (e.g. high claims) while other metrics
remain in normal ranges. The `anomaly_flag` column is the primary label for XGBoost training;
`risk_label` represents the WCS-derived band used for the CSP scorer evaluation.
